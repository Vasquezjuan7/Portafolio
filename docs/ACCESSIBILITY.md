# Accesibilidad y Cumplimiento WCAG

- **Navegación por Teclado**: Todo elemento interactivo es operable sin ratón.
- **Contraste de Color**: Ratios superiores a 4.5:1 en modo claro y oscuro.
- **Movimiento Reducido**: Animaciones pausadas con `prefers-reduced-motion`.
- **Textos Alternativos**: Cada captura incluye atributos `alt` enriquecidos.
