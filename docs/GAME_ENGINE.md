# Motor de Juego & Estado Reactivo

El portafolio implementa un HUD gamer sobre el contexto `GameProvider`.

## Características
1. **Telemetría de Nivel y XP**: Progresión simulada con nivel 24 y rango de ingeniería.
2. **Sistema de SFX**: Síntesis procedural en tiempo real mediante `Web Audio API`.
3. **Minimapa Reactivo**: Rastreabilidad de posición de lectura sobre el documento.
4. **Menú de Ajustes / Pausa**: Control de volumen, tema y modo de accesibilidad.
