# Generador de CV con jsPDF

El módulo `/components/cv.ts` sintetiza un documento PDF imprimible en tiempo de ejecución.

## Estructura Generada
- Encabezado con datos del desarrollador y enlaces verificados.
- Resumen profesional enfocado en frontend y software.
- Tabla de proyectos destacados con stack técnico.
- Historial académico y laboral cronológico.
