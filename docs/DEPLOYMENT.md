# Guía de Despliegue en Vercel

## Pasos de Despliegue
1. Conectar el repositorio de GitHub: `https://github.com/Vasquezjuan7/Portafolio.git`.
2. Framework Preset: **Next.js**.
3. Build Command: `next build` (o `next build --webpack` según entorno).
4. Variables de Entorno: Configurar `NEXT_PUBLIC_FORMSPREE_KEY` para el formulario de contacto.
